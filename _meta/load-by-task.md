# Load by task (beyond the warm-start spine)

Warm start already includes: `_meta` session files + **overview · architecture · principles · governance**.

Use this table for **additional** depth only. Open **one** extra doc when the task needs it — not the whole library.


| If the task is…                                                                                           | Open                                                                         |
| --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Citing or changing a locked structural choice (where data lives, apps/disks, structure agents vs workers) | [architecture/ADRs/](../architecture/ADRs/) — 0001 · 0002 · 0003 as relevant |
| Operate vs develop procedure (how to run the system day to day)                                           | [architecture/working-with.md](../architecture/working-with.md)              |
| Judgment that architecture docs don’t settle — *why* we built this way                                    | An **article** below (pick the matching row)                                 |
| How a life domain is *structured* for me (not live numbers)                                               | `domains/<area>/` when present                                               |
